## 📖 Project Overview

The **Apollo Apache IV LOS Prediction System** is a healthcare analytics platform developed using **Flask**, **Machine Learning**, and **Data Visualization** techniques. The system predicts the expected **Length of Stay (LOS)** of ICU patients based on APACHE IV clinical parameters, helping healthcare professionals make informed decisions.
